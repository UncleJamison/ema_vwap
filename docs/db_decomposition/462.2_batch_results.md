# Sub-bead 462.2: BatchResults DB (P3)

Dedicated database `batch_results.db` isolating optimization sweep outputs.

## Tables
- `batch_results` (main sweep table: id, exchange, symbol, timeframe, strategy_mode, target_metric, best_value, trade_count, sharpe_ratio, calmar_ratio, win_rate, max_drawdown_pct, total_return_pct, best_params, run_timestamp, favorite, validation_status, validation_json)
- `optuna_profiles` (hyperparameter profiles)
- `portfolio_balances` (portfolio tracking)
- Index: `idx_batch_results_metric` (target_metric, best_value DESC)

## Rationale
Re-sweeping is expensive; corruption of batch results must not wipe sweep history.

DB file created with schema; full code migration (update batch_optimizer references) deferred to 462.7.
