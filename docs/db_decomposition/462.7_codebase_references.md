# Sub-bead 462.7: Update all codebase references from monolithic to multi-DB access

## Summary
Updated every source file that directly instantiated `CandleDatabase()` or referenced `default_db`
to use the connection manager from 462.5 instead, routing each domain to its dedicated database.

## Changes Made

### Files updated (routing to dedicated DBs)

| File | Change | DB Domain |
|------|--------|-----------|
| `src/data_loader.py` | `from src.database import CandleDatabase` → `from src.db_connection_manager import get_database`; `db = get_database("candles")` | candles |
| `src/batch_optimizer.py` | Same pattern; `db = get_database("batch_results")` | batch_results |
| `src/paper/engine.py` | Same pattern; `self.db = db or get_database("paper_trading")` | paper_trading |
| `src/paper/ledger.py` | Same pattern; `self.db = db or get_database("paper_trading")` | paper_trading |
| `src/paper/profiles.py` | Same pattern; `self.db = db or get_database("paper_trading")` | paper_trading |
| `src/settings.py` | Same pattern; `self.db = db or get_database("system")` | system |
| `src/tasks.py` | Same pattern; `self.db = db or get_database("system")` | system |
| `src/alerting.py` | Inline import changed; `db = get_database("system")` | system |
| `src/app.py` | Module globals now use `get_database(key)` per domain: `_batch_db=get_database("batch_results")`, `_settings_mgr=SettingsManager(_system_db)`, `_paper_profiles=PaperProfileRegistry(_paper_db)`, `_paper_ledger=PaperLedger(_paper_db)`, `_paper_engine=PaperTradingEngine(db=_paper_db)` | all 4 |
| `src/db_connection_manager.py` | Added `get_database(db_key)` function returning `CandleDatabase(db_path=path)` | routing |

### Design choices
- Kept `CandleDatabase` type annotations intact for IDE/type-check compatibility.
- The monolithic `candles.db` is not used by any code path; all code routes to the dedicated DB files via `get_database()`.
- The `db = CandleDatabase()` global in `database.py:1996` was left intact for any external code that may import it (tests use their own instances).
- No test files were modified; all tests pass through direct `CandleDatabase(db_path=...)` construction.
